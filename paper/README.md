# Manuscript (provisional draft)

- `main.tex` uses ACM `acmart` (`sigconf,review,anonymous`). Compiling needs a TeX distribution that provides `acmart`. Build and check with `uv run python -m www_paper.gate` (tectonic).
- Every empirical number is a `\Num...` macro in `generated/numbers.tex`, `rescue_numbers.tex`, `unit_numbers.tex` or one of `posthoc`, `sweep`, `noise`, `anchor_ext`, `robust`, `td`, `bench` and `theory` `_numbers.tex`. `bench_numbers.tex` and `bench_table.tex` are parsed from `autoresearch/final_*.log` by `uv run python -m www_paper.bench_macros`. Regenerate with `uv run python -m www_paper.macros`, `www_paper.rescue_macros` and `www_paper.unit_macros`. Each macro line names its source report and JSON path.
- `tests/test_paper.py` fails if the generated numbers are stale, if a macro is undefined, if a bps or percent value is typed by hand (other than pre-specified design constants), if a citation lacks a bib entry, or if a bib entry is unused.
- `references.bib` holds only entries verified on 2026-10-11. Sections marked `[PENDING]` must not be filled with unmeasured values.
- Figures in `figures/` are generated by `uv run python -m www_paper.figures`, deterministically, with fixed PDF metadata. The anchor series comes from `reports/c3/anchor_15m_series.csv`, which holds derived 15-minute medians only. Rebuild that CSV from the audited panel with `--iaqf-panel PATH`. `tests/test_figures.py` checks that the committed PDFs are byte-identical to a regeneration.
